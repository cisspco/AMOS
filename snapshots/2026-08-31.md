WebGL GPU 지문 채취 및 서버 측 브라우저 환경 검증을 통해 분석 환경에는 무해한 콘텐츠를, 실제 피해자에게는 AMOS/MacSync ClickFix 루어를 조건부 제공. file<단어><단어> 도메인 명명 규칙 사용. 이전 캠페인 대비 회피 기능 대폭 강화. 페이로드는 /curl/<id> 경로 경유 전달. WebSocket 및 hidden 필드(mode:"php")를 활용한 핑거프린팅 게이트 구현. AMOS는 MacSync와 함께 배포됨.

### ClickFix macOS 유틸리티 루어 다변형 캠페인 (2026-05-06, Microsoft)
4가지 뚜렷한 AMOS 전달 변형:
- **Loader 캠페인** (2026-02): 러시아어권 도메인 60+개 인프라 활용, curl 파이프-to-셸 실행으로 AMOS 배포. 전용 봇 인프라(wusetail[.]com 등 5개)로 ClickFix 루어 관리.
- **Script 캠페인** (2026-04): script[.]sh URL 직접 배포, .icu/.digital TLD 도메인 및 스테이징 서브도메인 활용. 유출: 0x666[.]info, honestly[.]ink, pla7ina[.]cfd, play67[.]cc.
- **Helper 캠페인** (2026-01): 단일 단어 .com 도메인 24+개, AMOS "helper" 페이로드 배포. /contact 유출 엔드포인트 5개. Keychain 및 브라우저 자격증명 탈취.
- **Update 캠페인** (2026-02): 7개 도메인, AMOS 업데이트 패키지 위장 배포.
새로운 지속성 기법: Google Keystone/GoogleUpdate 앱 위장 LaunchAgent/Daemon 등록, ~/.mainhelper 백도어.

### ClawHavoc / OpenClaw AI 기반 배포 캠페인 (2026-02~03, Trend Micro)
AI 봇 마켓플레이스 ClawHub에 800개 이상의 악성 SKILL.md 파일 포함 스킬 게시. 피해자가 AI 에이전트 내 스킬 실행 시 AMOS 배포. clearl[.]co를 페이로드 전달 도메인으로 활용. macOS 생태계 내 AI 공급망 공격 경로 확인.

### SANS ISC AMOS 감염 사례 (2026-07-31)
getmacouscloud[.]com 에서 macOS Terminal ClickFix 루어 실행 유도, render65[.]com과 macostruecloud[.]xyz 경유 페이로드 전달, C2 서버 188.166.78[.]138에 TCP 80포트 /api/metrics/run POST 유출. AMOS Mach-O 바이너리 Application Support 디렉토리에 은닉.

### MacSync Stealer 인프라 헌팅 (2026-08-18, Microsoft) — AMOS 직접 귀속 없음
Microsoft가 행동 피벗(URI 패턴 `/curl/`, `/dynamic?txd=`, `/gate?buildtxd=`; curl 커맨드라인 패턴; api-key 헤더; 청크 업로드 파라미터)을 통해 MacSync C2 도메인 31개를 신규 식별. 보고서는 MacSync Stealer 전용으로 AMOS 귀속 없음 → AMOS IOC 목록 미포함. 관련 도메인(aihealthring[.]com, lumenagnet[.]com, plethorawallet[.]com 등 31개)은 MacSync 인프라로 별도 추적 권장.
