## 최근 캠페인 요약
- **ClickFix 은닉형 macOS 캠페인 (2026-08-05 보고)**: Microsoft가 추적한 캠페인. 브라우저 핑거프린팅(WebGL GPU 탐지, 숨겨진 mode:"php" 필드)으로 분석 환경을 식별하고 일반 사용자에게만 ClickFix 루어를 노출. 17개 이상의 file<단어><단어> 패턴 도메인 사용. AMOS 및 MacSync 인포스틸러 배포. /curl/<id> URL 패턴으로 원격 AppleScript 실행. 검색 스니펫에 따르면 실제로는 250개 이상의 프런트엔드 도메인이 사용된 것으로 보고됨(원문 EGRESS_BLOCKED, IOC 미검증).
- **ClickFix 가짜 macOS 유틸리티 캠페인 (2026-05-06 보고)**: Microsoft 분석. 세 가지 하위 캠페인(Loader, Script, Helper)으로 구성. Helper 캠페인이 AMOS(Atomic Stealer)를 배포하며 30개의 전용 C2/유출 도메인 운용. ~/Library/LaunchDaemons/com.finder.helper.plist로 지속성 확보, ~/.mainhelper 및 ~/.agent 래퍼 파일 생성. 크립토 지갑 앱(Trezor, Ledger, Exodus 등)을 트로이목마 버전으로 교체하는 기능 포함.
- **AMOS getmacouscloud 캠페인 (2026-08-02 보고)**: SANS ISC가 2026-07-31 랩 감염에서 포착. getmacouscloud[.]com이 "macOS toolkit" 설치를 가장한 터미널 명령 실행을 유도. C2 188.166.78[.]138으로 ZIP 압축 데이터 HTTP POST 전송.
- **AMOS OpenClaw 캠페인 (2026-02/03 보고)**: Trend Micro 보고. OpenClaw AI 어시스턴트 위장, clearl[.]co를 통해 AMOS 페이로드 배포, 92.246.136[.]14를 보조 C2로 사용.
- **AMOS codex-tips 캠페인 (2026-08 보고)**: Brinztech 경보. codex-tips[.]com을 통해 개발자 문서 사이트로 위장하여 AMOS 배포. 환경 분석 방지 기능 및 안티-VM 체크 포함.
- **AMOS AI 에이전트 도구 위장 캠페인 (2026, 검색 스니펫)**: Moonlock 보고 (EGRESS_BLOCKED). AMOS가 macOS AI 에이전트 도구를 위장하여 배포 — 원문 미확인, IOC 미검증.
- **EvilTokens + ClickFix AMOS 캠페인 (2026-03, 검색 스니펫)**: CybersecurityNews 보고 (EGRESS_BLOCKED). EvilTokens와 결합한 ClickFix 캠페인으로 AMOS 배포 — 원문 미확인, IOC 미검증.
- **AMOS Spectrum 테마 ClickFix 캠페인 (2026, 검색 스니펫)**: CloudSEK 보고 (EGRESS_BLOCKED). 러시아어권 해커가 Spectrum 브랜드 테마 ClickFix 루어로 AMOS 변형 배포 — 원문 미확인, IOC 미검증.
- **AMOS Polygon 스마트 컨트랙트 크라임킷 (2026, 검색 스니펫)**: GBHackers 보고 (EGRESS_BLOCKED). Polygon 블록체인 스마트 컨트랙트를 C2 리졸루션에 활용하는 ClickFix 크라임킷으로 AMOS 및 XMRig 배포 — 원문 미확인, IOC 미검증.
